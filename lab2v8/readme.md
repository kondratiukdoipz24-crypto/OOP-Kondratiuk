# Лабораторна робота №2

## Тема

Клас із кількома конструкторами. Життєвий цикл об’єкта.

## Мета роботи

Навчитися реалізовувати перевантажені конструктори, дослідити порядок їх викликів та зрозуміти основи життєвого циклу об’єкта в C#.

## Варіант

**8 — Клас Animal**

### Завдання

Реалізувати клас `Animal` з такими елементами:

* приватні поля:

  * `_species` — вид тварини;
  * `_nickname` — кличка;
  * `_age` — вік;
* публічні властивості `Species`, `Nickname`, `Age`;
* для властивості `Age` реалізувати валідацію: вік не може бути від’ємним;
* мінімум два перевантажені конструктори;
* один конструктор повинен викликати інший за допомогою `: this()`;
* метод `Speak()` для виведення звуку, характерного для виду тварини;
* деструктор (фіналізатор), який виводить повідомлення про знищення об’єкта.

## Конструктори

### Конструктор за замовчуванням

* `Species = "Unknown"`
* `Nickname = "Unnamed"`
* `Age = 0`

### Параметризований конструктор

Приймає:

* `species`
* `nickname`
* `age`

## Демонстрація роботи

У методі `Main` необхідно:

1. Створити 2–3 об’єкти класу `Animal`, використовуючи різні конструктори.
2. Викликати метод `Speak()` для створених об’єктів.
3. Вивести результати роботи програми в консоль.
4. Наприкінці виконати:
   `GC.Collect();`
   `GC.WaitForPendingFinalizers();`
5. Продемонструвати повідомлення з деструкторів.

## Очікуваний результат

Програма демонструє:

* роботу перевантажених конструкторів;
* ланцюговий виклик конструкторів через `: this()`;
* валідацію віку тварини;
* роботу методу `Speak()`;
* життєвий цикл об’єкта;
* роботу збирача сміття та фіналізатора.

## Висновок

Під час виконання лабораторної роботи було реалізовано клас `Animal` з приватними полями, публічними властивостями та валідацією віку. Було створено кілька перевантажених конструкторів, один з яких викликає інший за допомогою `: this()`. Також було реалізовано метод `Speak()` та деструктор. У методі `Main` продемонстровано створення об’єктів різними конструкторами та роботу збирача сміття. Я навчилася розуміти основні етапи життєвого циклу об’єкта в C#.
