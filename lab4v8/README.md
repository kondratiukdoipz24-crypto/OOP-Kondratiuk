# Лабораторна робота №4

## Тема

Наслідування. Ключові слова base, override, virtual. Приховування членів (new).

## Виконавець

Кондратюк Дарина  
Група: ІПЗ-3/1  
Варіант: 8

## Мета роботи

Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new.

## Індивідуальний варіант

Ієрархія:

Device → Smartphone → Laptop

### Device

Базовий клас містить:

- Brand;
- Model;
- конструктор;
- virtual метод PowerOn();
- метод GetDeviceType().

### Smartphone

Похідний клас містить:

- ScreenSize;
- override метод PowerOn();
- метод MakeCall();
- конструктор з викликом base();
- new метод GetDeviceType().

### Laptop

Похідний клас містить:

- Processor;
- override метод PowerOn();
- метод RunProgram();
- конструктор з викликом base().

## Реалізовані можливості

У програмі продемонстровано:

1. Наслідування класів.
2. Використання конструктора базового класу через base().
3. Використання virtual.
4. Перевизначення методу через override.
5. Поліморфізм.
6. Приховування методу через new.
7. Різницю між override та new.

## Контрольні питання

### 1. Поясніть принцип наслідування в ООП. Наведіть приклад з реального світу.

Наслідування дозволяє створювати новий клас на основі вже існуючого. Похідний клас отримує властивості та методи базового класу і може додавати власні.

У цій роботі класи Smartphone і Laptop наслідуються від Device.

Приклад з реального світу: смартфон і ноутбук є різновидами електронних пристроїв.
